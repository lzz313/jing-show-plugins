# jing.show for Orca

For the formal GitHub install (plugin key `lzz313.jing-show`), see the
[root README](README.md). This file covers the panel, the development folder
(key `local.jing-show`) and development notes.

A right-sidebar Orca panel for the jing.show timeline, backed by a trusted
worker. The panel shows latest / hot / rising, filters by source, keeps the
original title beside its Chinese translation, and summarizes the selected
item **inline with the local model router** — no agent session.

```
orca-plugin.json
src/
  panel.tsx            # components panel (no network, no DOM)
  protocol.ts          # typed panel <-> worker contract
  worker.ts            # fetch + local model summary
  panel.check.ts       # offline check scenarios
  vendor/jing-client.mjs
```

## Install for development

```sh
ORCA=/Applications/Orca.app/Contents/Resources/bin/orca
"$ORCA" plugin validate . --json
"$ORCA" plugin types .
npx tsc -p .
"$ORCA" plugin test . --json
"$ORCA" plugin check . --json
"$ORCA" plugin dev load . --json       # first run prints the approval fingerprint
"$ORCA" plugin dev load . --approve <fingerprint> --json
"$ORCA" plugin open local.jing-show --panel jing-feed
```

The first load asks for three capabilities:

- `agent:read` — read the focused workspace's agents (fallback when the local
  router is down).
- `terminal:send` — paste a summary prompt into one agent terminal.
- `storage:own` — remember the last view, source and summary model.

## Uninstall

A development folder is unregistered with `dev unload` (`uninstall` does not
handle development folders):

```sh
"$ORCA" plugin dev unload .
# or: "$ORCA" plugin dev unload local.jing-show
```

This removes the folder from Settings → Plugins → Development folders and
leaves the checkout untouched. A formal install from GitHub is removed with:

```sh
"$ORCA" plugin uninstall lzz313.jing-show
```

`uninstall` needs no approval; it removes the plugin files, approval and theme
choices. Use `orca plugin disable <plugin-key>` to turn it off temporarily.

## Use

The panel defaults to **latest**. One header row holds the latest/hot/rising
view links on the left and, on the right, a small logo with the `jing.show`
wordmark, the source select, the update time and a refresh button. The active
view is a filled badge; the source select narrows the list. Each card has:

- **打开** — open the original URL in the default browser.
- **总结** — summarize the item inline with the local model. The block appears
  under the card, headed by the model and level, and renders the answer as
  Markdown.
- **再总结** / **收起** — summarize again, or close the block.
- **发给本地 Agent** — appears only when the local router cannot be reached:
  the worker falls back to sending the prompt to a local agent, or shows the
  prompt in a textarea when none is available.

English titles and summaries are kept, with the Chinese translation on the next
line: the original is muted, the translation uses the card's body weight.

`加载更多` at the footer asks the worker for the next older page of the latest
view and appends it to the same list.

### Model and level

`模型设置` is a button beside `加载更多` at the bottom; it opens a panel with
two selects:

- **模型** — `GET /v1/models` from the local router, labelled with the router's
  `display_name`.
- **级别** — the reasoning levels that model accepts (`低` / `中` / `高` /
  `很高` / `最高` / `极致`), plus `默认（不指定）`.

The choice is kept in the plugin's persisted atom and shown in the panel's
`当前：…` line and the button tooltip. With no pick, the defaults come from
`~/.claude/settings.json`:
`env.ANTHROPIC_SMALL_FAST_MODEL` (the `[1m]` context suffix is stripped) and
that model's `modelSettings.effortLevel`. The selected level is posted as
`output_config.effort` together with adaptive thinking — the shape the router
reads. The prompt contains only the title, short summary, source, time and
link; it marks the text as untrusted and tells the model not to execute
instructions found in it.

## Agents

The same public data is available to local agents over the read-only MCP
endpoint `https://jing.show/mcp`: `codex mcp add jing --url
https://jing.show/mcp`, or the Codex plugin in [`codex/`](codex/). T3 Code
uses the same endpoint through the agents it runs; see
[`t3/README.md`](t3/README.md).

## Development notes

- The panel has no network access: all requests go through
  `plugin.request` to `src/worker.ts`. The worker is Node, so it reads
  `~/.claude/settings.json` and calls the local router directly.
- `terminal.sendText` is worker-only; the panel cannot type into a terminal.
- The worker caches a feed page for 60 seconds and the model catalog for five
  minutes. The panel refreshes every 5 minutes while visible.
- Do not edit `.orca/`; it is generated by `orca plugin types`.
- After editing `shared/jing-client.mjs`, run
  `node scripts/sync-plugin-shared.mjs`.
