# jing.show plugins

jing.show in the tools you already use:

- **Orca** — a right-sidebar panel with the latest / hot / rising timeline,
  source filtering, inline local-model summaries and an agent fallback. The
  plugin is at the repository root (`orca-plugin.json`).
- **Herdr** — a normal pane with the same feed and an inline `Shift+S` summary.
  The mod is in [`herdr/jing-show/`](herdr/jing-show/).
- **Codex** — a read-only MCP server plus a `jing-news` skill. The plugin is in
  [`codex/`](codex/), and this repository is a Codex marketplace
  (`.agents/plugins/marketplace.json`).
- **T3 Code** — T3 has no third-party plugin host; configure the Claude Code /
  Codex agents it runs to use the same MCP endpoint. See
  [`t3/README.md`](t3/README.md).

`shared/jing-client.mjs` is the canonical host-neutral client; the copies in
`src/vendor/` and `herdr/jing-show/lib/` are generated by
`node scripts/sync-plugin-shared.mjs`.

## Requirements

- Orca 1.4.248+ for the Orca panel, or Herdr 0.1.x for the mod.
- Network access to `https://jing.show`.
- For summaries, Claude Code's local model router on the same machine. The
  worker and the mod read `~/.claude/settings.json`:
  `env.ANTHROPIC_BASE_URL` (default `http://127.0.0.1:3425`),
  `env.ANTHROPIC_AUTH_TOKEN`, `env.ANTHROPIC_SMALL_FAST_MODEL`, and that
  model's `modelSettings.effortLevel`. Without it the feed still works; the
  summary shows an error and offers the agent fallback.

## Orca: formal install from this repository

Install from the GitHub repository so Orca pins the exact commit and can
update it later:

```sh
ORCA=/Applications/Orca.app/Contents/Resources/bin/orca

"$ORCA" plugin install lzz313/jing-show-plugins --json
# approval_required: re-run with the fingerprint it printed
"$ORCA" plugin install lzz313/jing-show-plugins --approve <fingerprint> --json

"$ORCA" plugin open lzz313.jing-show --panel jing-feed
```

The plugin key is **`lzz313.jing-show`** (publisher = repository owner). The
repository is public, so no GitHub sign-in is needed on the Orca host.

Update a Git install to the newest `vX.Y.Z` tag:

```sh
"$ORCA" plugin update lzz313.jing-show --json
```

Uninstall:

```sh
"$ORCA" plugin uninstall lzz313.jing-show --json
```

### Orca development

Clone the repository and load the root as a development folder; the key is
then `local.jing-show`:

```sh
"$ORCA" plugin validate . --json
"$ORCA" plugin types .
npx tsc -p .
"$ORCA" plugin test .
"$ORCA" plugin check .
"$ORCA" plugin dev load . --json
"$ORCA" plugin dev load . --approve <fingerprint> --json
"$ORCA" plugin open local.jing-show --panel jing-feed
```

See [`ORCA.md`](ORCA.md) for panel usage, the model picker and development
notes.

## Herdr: install the mod

Herdr only sees real folders under `~/.config/herdr-app/mods/`; symlinked mod
directories are not listed, so copy the folder:

```sh
git clone https://github.com/lzz313/jing-show-plugins.git
cd jing-show-plugins

rm -rf ~/.config/herdr-app/mods/jing-show
cp -R herdr/jing-show ~/.config/herdr-app/mods/jing-show

~/.local/bin/herdr-app check ~/.config/herdr-app/mods/jing-show
~/.local/bin/herdr-app do tab.new --name "jing.show" --mod jing-show
```

Update with `git pull` and copy the folder again. Uninstall by closing the
pane/tab and removing the folder:

```sh
rm -rf ~/.config/herdr-app/mods/jing-show
```

The optional tab-bar button and colorful pane-header logo are patches to the
shipped Herdr mods, described in
[`herdr/jing-show/README.md`](herdr/jing-show/README.md). If you added them,
clean those up too.

## Codex and other MCP clients

The jingkan Worker serves a stateless, read-only MCP endpoint at
`https://jing.show/mcp`. The simplest install needs no plugin at all:

```sh
codex mcp add jing --url https://jing.show/mcp
codex mcp list
```

For the `jing-news` skill (workflow and untrusted-content rules), add this
repository as a Codex marketplace and install the plugin:

```sh
codex plugin marketplace add lzz313/jing-show-plugins
codex plugin list
# then install/enable jing-show from /plugins, or:
codex plugin add jing-show@jing-show-plugins
```

See [`codex/README.md`](codex/README.md) for the tool list, the local-checkout
flow and the transport notes. T3 Code needs no plugin files: it runs Claude
Code / Codex, so configure those agents with the same MCP server; see
[`t3/README.md`](t3/README.md).

## Development

```sh
node scripts/sync-plugin-shared.mjs          # copy shared/ into both plugins
node scripts/sync-plugin-shared.mjs --check  # fail on drift
npm test                                     # zero-dependency client tests

cd jing-show-plugins
"$ORCA" plugin test .
"$ORCA" plugin check .

~/.local/bin/herdr-app check herdr/jing-show
```

CI runs `npm run sync:check`, validates the JSON manifests and runs
`npm test`.

Do not edit the generated copies in `src/vendor/` or `herdr/jing-show/lib/`
directly.
